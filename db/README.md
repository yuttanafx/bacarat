# ฐานข้อมูลบาคาร่า (API + Webhook)

ข้อมูลจาก Kaggle `coulbynguyen/baccarat-data-set-5-27-24` แปลงเป็นกระดานแล้ว: 8,407,444 ตา = 111,400 กระดาน
เก็บใน `baccarat.db` (SQLite, ~25 MB) ไม่ต้องใช้ไฟล์ CSV 593 MB อีก ใช้ Python 3 ล้วน ไม่ต้องติดตั้งไลบรารี

## วิธีที่ 1: ไม่ต้องมีเซิร์ฟเวอร์ (ใช้บน GitHub Pages ได้)
ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data/` (57 ไฟล์ ~8 MB) ที่ต้องอัปโหลดไปพร้อม `index.html`
เปิดหน้าเว็บผ่าน http/https แล้วกด "ดึงจากไฟล์ข้อมูลในเว็บ" ในส่วน "ฐานข้อมูลกลาง"
(เปิด `index.html` ตรง ๆ จากไฟล์ในเครื่องไม่ได้ เบราว์เซอร์บล็อก ให้รัน `python3 -m http.server` ในโฟลเดอร์โปรเจกต์ แล้วเปิด http://localhost:8000)
ถ้าสร้างไฟล์ `data/` ใหม่จาก `baccarat.db`: `python3 db/export_static.py`
ข้อจำกัด: วิธีนี้อ่านได้อย่างเดียว รับ webhook กลับเข้าฐานข้อมูลไม่ได้ และมีเฉพาะชุด Kaggle

## วิธีที่ 2: เซิร์ฟเวอร์ฐานข้อมูล (API + รับ Webhook)
ต้องมี `baccarat.db` ในโฟลเดอร์ `db/` (สร้างจาก CSV ด้วย `import_csv.py` ด้านล่าง)

### เริ่มใช้งานเซิร์ฟเวอร์
```
cd db
python3 server.py
```
เปิด http://localhost:8787 หน้าเว็บจะมาจากเซิร์ฟเวอร์เดียวกัน แล้วไปที่ส่วน "ฐานข้อมูลกลาง"
กด "ทดสอบการเชื่อมต่อ" แล้ว "ดึงกระดานจากฐานข้อมูล"

ถ้าเปิด `index.html` ตรง ๆ จากไฟล์ ให้กรอก URL เป็น `http://localhost:8787` เอง

## รับกระดานที่เล่นเองกลับเข้าฐานข้อมูล
กด "ตั้ง Webhook ให้ส่งกระดานเข้าฐานข้อมูลนี้" ทุกครั้งที่กด "จบกระดาน" หน้าเว็บจะ POST มาที่ `/hook`
กระดานเหล่านี้ติดแท็กตามที่ตั้งในหน้าเว็บ แยกจากชุด Kaggle และดึงกลับมาใช้บนเครื่องอื่นได้

## ใช้งานผ่านอินเทอร์เน็ต
```
BACC_TOKEN=รหัสลับ python3 server.py --host 0.0.0.0 --port 8787
```
ใส่โทเคนเดียวกันในช่อง "โทเคน" ของหน้าเว็บ หน้าเว็บที่เปิดผ่าน https ต้องใช้ฐานข้อมูลที่เป็น https ด้วย
(ใช้ reverse proxy เช่น Caddy / nginx / Cloudflare Tunnel) ไม่เช่นนั้นเบราว์เซอร์จะบล็อก

## เส้นทาง API
| เส้นทาง | หน้าที่ |
|---|---|
| `GET /api/health` | ตรวจสถานะ (ไม่ต้องใช้โทเคน) |
| `GET /api/stats` | จำนวนกระดาน/ตา และสัดส่วน B/P/T แยกตามแท็ก |
| `GET /api/boards?limit=300&tag=&min_hands=&max_hands=&order=random\|latest\|oldest&offset=` | ดึงกระดาน (สูงสุด 2,000 ต่อครั้ง) |
| `GET /api/boards/<id>` | ดึงกระดานเดียว |
| `POST /hook` | `{"event":"board_finished","board":{...}}`, `{"event":"export_boards","boards":[...]}` หรือ `{"event":"test"}` |

โทเคนส่งได้ทาง header `X-API-Key`, `Authorization: Bearer …` หรือ `?key=…`
ผลลัพธ์ของ `/api/boards` มี `boards[]` แบบเดียวกับไฟล์สำรองของหน้าเว็บ

## สร้างฐานข้อมูลใหม่จาก CSV
```
python3 import_csv.py baccaratDataSet.csv --db baccarat.db
```
กติกาแปลง: `winner` 1 = Banker, -1 = Player, 0 = Tie และแถวที่ `last winner` = -100 คือตาแรกของสำรับใหม่
(ตรวจกับยอดไพ่จริงและความต่อเนื่องทุกแถวแล้ว ไม่พบข้อผิดพลาด)
ฐานข้อมูลเก็บเฉพาะลำดับผลต่อกระดาน ไม่รวมคอลัมน์ไพ่ที่เปิดไปแล้ว/ยอดไพ่ ซึ่งหน้าเว็บไม่ได้ใช้
